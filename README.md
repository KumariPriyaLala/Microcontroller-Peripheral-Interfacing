Project under Microcontrollers & Microprocessors Course.
used 8051 (Nuvoton W78E52D), Assembly, Keil µVision 
Programmed an 8051-family microcontroller (Nuvoton W78E52D) in assembly language using Keil µVision to control GPIO-based LED outputs and poll digital switch inputs via direct port/bit manipulation.
Interfaced a 16x2 LCD (4-bit mode) and implemented UART/RS232 serial communication, while configuring on- chip timers and external hardware interrupts (INT0, INT1) for precise delays and asynchronous event handling.
Flashed and verified firmware using the Nuvoton ISP-ICP utility, testing functionality on a hardware trainer kit with LED, switch, keypad, and LCD add-on modules
